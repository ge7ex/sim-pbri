## Design Context

Source: user-supplied UI Alignment Checkpoint, 2026-10-07.

### Users
Lecturers request simulation rooms and equipment; college Staff review bookings; college Admin manage rooms, simulator assets and scenario templates.

### Brand Personality
Calm, institutional, clear. A Thai simulation-center administration product with readable workflows and explicit role context.

### Aesthetic Direction
Follow ge7ex/sim-pbri-preview main (2314dd2): deep navy sidebar, slate text, white panels and soft gray background. Retain current Thai font stack. This checkpoint aligns an established visual direction; no new decorative direction or marketing surfaces.

### Design Principles
- Visual reference supplies structure and tokens; real Inertia data supplies content.
- Permission-aware navigation, with server authorization remaining authoritative.
- Compact readable tables and forms with keyboard focus and practical mobile navigation.
- Preserve college isolation, financial privacy and all booking checks.
- Reuse shared primitives incrementally; leave module-specific layout scoped.
